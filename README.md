# Employee Leave Analysis

## Python Data Analysis Project

### Objective

Analyze employee data and identify patterns associated with employee leave.

### Dataset

The dataset contains employee information such as:

* Education
* Joining Year
* City
* Payment Tier
* Age
* Gender
* Ever Benched
* Experience in Current Domain
* Leave or Not

### Analysis Performed

* Data understanding and exploration
* Missing value check
* Duplicate value check
* Employee leave distribution analysis
* Leave rate analysis by education, gender, payment tier, city, and experience
* Data visualization using charts
* Key findings identification

### Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook
* VS Code

### Project Files

* `employee_analysis.ipynb` — Jupyter Notebook containing the complete analysis
* `employee_data.csv` — Original dataset
* `employee_analysis_cleaned.csv` — Cleaned dataset
